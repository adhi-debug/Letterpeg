# Text to Image

Professional quote image generator for social media, designed to produce high-quality Instagram-ready visuals in seconds. Built by **adhi-debug** with a focus on speed, style, and local browser rendering.

---

## Live Demo

https://text-to-img-theta.vercel.app/

---

## What You Get

- Modern canvas-based quote design generator
- 12 premium mesh gradient backgrounds
- 27+ curated display fonts from Google Fonts
- Responsive preview with instant updates
- Custom text color options plus native color picker
- Adjustable font size from 32px to 120px
- Grain texture and vignette styling controls
- One-click PNG export at 1080x1350px
- Completely client-side rendering, no backend required

---

## Tech Stack

- React with Vite for fast development
- Vanilla CSS for lightweight styling
- Canvas API for export quality image generation
- Google Fonts for premium typography
- Deployed on Vercel for instant live preview

---

## Usage

1. Enter your quote or headline text.
2. Choose a gradient background.
3. Select a font and adjust the size.
4. Pick a text color or use the custom color picker.
5. Enable grain and vignette effects as needed.
6. Click **Download PNG** to save a high-resolution image.

---

## Why This Works

This project is ideal for content creators, marketers, and designers who need polished quote graphics without complex design tools. It keeps everything local, maintains privacy, and delivers consistent export results.

---

## Installation

```bash
# Clone the repository
git clone <YOUR_REPO_URL>

# Navigate to the project folder
cd text-to-img-main/Letterpeg

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Open the local Vite URL shown in your terminal to preview the app.
